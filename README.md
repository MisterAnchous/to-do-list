# to-do лист

Русскоязычное приложение для управления задачами и списками. Чистый HTML, CSS, JavaScript, SVG и Web Animations API. Сборка и установка пакетов не нужны.

## Запуск

Откройте терминал в этой папке и выполните:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

## Использование

- Введите задачу и нажмите `Enter` или кнопку со стрелкой. `Shift+Enter` переносит строку.
- Нажмите на чекбокс, чтобы выполнить задачу или вернуть её в активные.
- Создавайте списки кнопкой «Новый список» или клавишей `N`, когда не редактируете текст. Подтвердите название клавишей `Enter`; `Escape` отменяет ввод.
- У списка можно выбрать цвет из палитры, свой HEX-цвет (`#8843ff` или `#83f`) или эмодзи. Нажмите на значок при создании, рядом с заголовком списка или выберите «Значок и цвет» в меню `…`. Оформление сохраняется вместе со списком. Неверный HEX не применяется.
- Меню `…` позволяет переименовать список, переместить задачу в другой список или отправить объект в корзину.
- В корзине можно восстановить объект или удалить его навсегда. Удаление навсегда и очистка корзины требуют подтверждения.
- Кнопка сверху справа открывает три темы: светлую, тёмную и чёрную. На узком экране кнопка сверху слева открывает навигацию.
- Меню поддерживают стрелки, `Home`, `End` и `Escape`. Учтена системная настройка уменьшения движения.

## Данные

При первом запуске приложение пустое. Задачи, списки с их оформлением, корзина и тема сохраняются одной записью `todo-list:v1` в `localStorage` после каждого изменения. Списки, сохранённые до добавления выбора оформления, остаются доступны со своим прежним цветом.

Данные относятся к текущему браузеру и адресу сайта: `127.0.0.1:4173`, `localhost:4173` и другие порты имеют отдельные хранилища. При очистке данных браузера они удаляются. Сервера, учётной записи, синхронизации и автоматической очистки корзины нет. Если браузер запрещает сохранение, приложение продолжает работать и показывает уведомление.

Удалённый список скрывает все свои задачи. При восстановлении списка задачи, удалённые отдельно до него, остаются в корзине. Окончательное удаление списка удаляет все связанные задачи, в том числе ранее удалённые отдельно.

## Файлы

- `index.html` — разметка и применение сохранённой темы до отображения страницы.
- `styles.css` — адаптивный интерфейс и три палитры.
- `app.js` — модель данных, сохранение, взаимодействия и анимации.
- `sapphire-icon-set/` — оптимизированные WebP на основе изображений пользователя для разделов, списков и пустых состояний.
- `assets/InterVariable.woff2` — локальный официальный шрифт Inter, включая кириллицу.
- `assets/Inter-LICENSE.txt` — лицензия SIL Open Font License.

## Интерфейс и движение

Верхнее освещение поддерживает тему: розовое в светлой, приглушённое лиловое в тёмной и синее в чёрной. Широкая засветка мягко затухает вниз; внутри списка она принимает его цвет с плавным переходом 850 мс. Быстрое переключение продолжает переход из текущего оттенка. Постоянной пульсации нет.

Иконки из `sapphire-icon-set/` используются для всех списков без эмодзи, включая поле нового списка. Для произвольного HEX выбирается ближайший оттенок Sapphire; точный цвет сохраняется в данных, подсветке списка и палитре.

Компактные служебные SVG-иконки и шрифт Inter дополняют спокойное оформление интерфейса. Пустой экран содержит один значок и короткую подпись. Значок пустого списка повторяет выбранный Sapphire или эмодзи. Декоративного блока внизу навигации нет. Ошибки сохранения показываются уведомлением.

- Строка навигации — 42 px, поле добавления — 48 px, заголовок — 20 px. На сенсорных экранах области нажатия увеличены.
- Общий индикатор навигации перемещается за 260 мс, содержимое раздела появляется за 200 мс, пустое состояние — за 180 мс.
- Меню: вход 220 мс, выход 120 мс; пункты появляются с интервалом 20 мс, общая задержка ограничена 80 мс.
- Чекбокс — 420 мс, новая строка — 180 мс, удаление — 160 мс, перемещение соседних строк — 220 мс.
- Основной easing: `cubic-bezier(.2,.8,.2,1)`. Поворотов и подпрыгивания декоративных объектов нет.

Навигация использует постоянные DOM-элементы и общий индикатор. Повторное действие продолжает движение из текущего положения; операции с данными выполняются сразу. Системная настройка уменьшения движения убирает перемещения, деформацию и задержки, оставляя короткое изменение прозрачности. Включение настройки во время работы отменяет уже запущенные WAAPI-анимации.
